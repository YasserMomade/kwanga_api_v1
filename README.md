# Laravel Personal Management API

A scalable RESTful API built with Laravel designed for personal productivity and life management.  
The platform allows users to plan long-term life goals, manage projects and tasks, organize lists, and engage in community-driven challenges with progress tracking and rankings.

---

## 🚀 Features

### 🧠 Personal Planning
- Create long-term life plans by area (career, health, finance, personal growth, etc.)
- Define yearly and monthly goals
- Track progress over time

### 📁 Projects & Tasks
- Create projects
- Add tasks within projects
- Task status management (pending, in progress, completed)
- Deadline and priority support

### 📝 Lists
- Create custom lists
- Add tasks to lists
- Flexible organization for personal workflows

### 🌍 Community & Challenges
- Create and join communities
- Create challenges inside communities
- Participate in challenges
- Track challenge progress
- View rankings and leaderboards

## 🔄 Example User Flow

1. User creates an account and logs in.
2. User defines long-term plans in different life areas.
3. User sets yearly and monthly goals.
4. User creates projects and tasks related to their goals.
5. User organizes tasks using custom lists.
6. User joins a community and participates in challenges.
7. User tracks progress and views challenge rankings.
